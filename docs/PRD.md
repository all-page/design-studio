# 사이트 설계도(PRD) — 디자인 포트폴리오 & 주문 상담 (사이트 이름 미정)

작성일: 2026-10-17 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
로고·브랜딩, 상세페이지·SNS, 인쇄물·패키지 디자인 작업물을 보여 주고, 디자인이 필요한 분이 바로 무료 상담을 신청할 수 있는 곳.

## 2. 손님
- 누가: 소상공인·가게 사장님, 온라인 쇼핑몰 운영자, 1인 사업자·프리랜서 (그 밖의 손님: 미정)
- 어디서 알고 오나: 인스타그램, 검색 (그 밖의 길: 미정)

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 가격·견적 — 얼마인지
2. 작업 기간 — 며칠 걸리는지
3. 수정 횟수 — 몇 번 고쳐 주는지
4. 진행 과정 — 상담 → 시안 → 완성이 어떻게 흘러가는지
- (그 밖의 궁금한 것: 미정)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 작업물(포트폴리오): 로고·브랜딩 / 상세페이지·SNS / 인쇄물·패키지 — 실제 이미지는 사용자가 준비 (미정)
- 후기: 실제 고객 후기 있음 — 원문은 사용자가 준비해서 그대로 넣는다 (지어내지 않음)
- (그 밖의 증거: 미정)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 무료 상담 신청
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로, 한 페이지)
1. 첫 화면 — 한 문장 + [무료 상담 신청] 버튼
2. 이런 디자인을 해요 — 로고·브랜딩 / 상세페이지·SNS / 인쇄물·패키지 (3칸)
3. 포트폴리오 — 분야별로 나눠 보는 작업물 이미지
4. 진행 과정 — 상담 → 시안 → 수정 → 완성 (단계만, 기간·횟수는 확정 후 표기)
5. 자주 묻는 질문 — 가격·작업 기간·수정 횟수 (답은 "상담 시 안내" 또는 확정 값)
6. 고객 후기 — 실제 후기 (사용자가 준 원문만)
7. 무료 상담 신청 폼

## 7. 문의 폼에서 받을 것
- 이름, 연락처
- 필요한 디자인 종류 (로고·브랜딩 / 상세페이지·SNS / 인쇄물·패키지 / 기타)
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: (미정 — 준비 중)
- 작업 기간: (미정 — 준비 중)
- 수정 횟수: (미정 — 준비 중)
- 연락 방법: (미정 — 준비 중)
- 위치: 해당 없음 (온라인 작업)

## 9. 이번에 넣지 않을 것
- 회원가입·로그인
- 온라인 결제
- 손님이 참고 이미지 파일 올리기
- 새 문의 알림 메일
- 블로그

## 10. 첫 화면 한 문장 후보
1. 가게와 브랜드의 첫인상, 로고부터 상세페이지까지 함께 만듭니다.
2. 로고·상세페이지·패키지 — 필요한 디자인을 한곳에서 상담하세요.
3. 작업물을 먼저 보고, 마음에 들면 편하게 무료 상담을 신청하세요.

## 11. 다음에 할 것
- 가격·작업 기간·수정 횟수·연락 방법 확정해서 8번 채우기
- 포트폴리오 이미지와 실제 후기 원문 준비
- 사이트 이름 정하기
- 질문 2·3·4번에서 고른 "그 밖의 것(Something else)" 내용 채우기
- (나중) 참고 파일 올리기, 새 문의 알림 메일

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 고급스러운 (어두운 바탕, 넓은 여백, 갤러리 느낌) · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
